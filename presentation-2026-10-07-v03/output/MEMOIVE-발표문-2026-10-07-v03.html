질문 대응

1. 기존 AI 도구와 무엇이 다른가요?

AI가 더 잘 답한다고 주장하지 않습니다. 차별화 가설은 원문, 저장 이유, 내 생각, 진행 중인 결과물을 함께 보관해 다음 작업에서 맥락을 다시 설명하는 수고를 줄이는 것입니다. 같은 과제를 기존 도구와 비교해 실제 차이를 확인해야 합니다.

2. 어느 주소로 들어가도 기록이 자동으로 보이나요?

허용된 배포 화면은 같은 Vercel 기록 API와 TOBEA Supabase를 사용합니다. 다만 새 주소나 새 브라우저는 별도 저장 공간이므로, 다른 기기 연결 링크를 한 번 열어 소유자 코드를 연결해야 합니다. 이후에는 같은 기록을 읽고 저장합니다.

3. 현재 확인한 성과는 무엇인가요?

기록 13개와 결과물 2개를 Supabase에 저장하고 운영 화면에서 다시 불러온 것을 확인했습니다. 한화 영상 사례에서 자막, AI 정리, 내 생각, 창작 화면 연결도 확인했습니다. 외부 사용자의 수요와 시간 단축, 장기 사용은 아직 검증하지 않았습니다.

4. 개인 기록은 공개 GitHub에 올라가나요?

올리지 않습니다. GitHub에는 코드, 공개 가능한 문서, 발표자료만 둡니다. 개인 기록은 소유자 코드로 보호되는 Supabase에 저장하고, 원본 코드는 배포 환경의 비밀 설정값으로도 저장하지 않습니다.

5. Cloudflare에는 무엇이 있나요?

Cloudflare Worker는 브라우저에 Gemini API 키를 노출하지 않고 AI 요청을 전달하는 중간 서버입니다. 기록의 기준 저장소는 Cloudflare가 아니라 TOBEA Supabase입니다. 화면을 다른 배포처에 두어도 같은 Vercel 기록 API를 바라보게 설계했습니다.

6. 여러 사용자가 함께 써도 되나요?

현재 방식은 한 사람의 여러 기기를 위한 개인용 동기화입니다. 여러 사용자를 받으려면 계정별 인증, 데이터 분리, 삭제와 복구 정책, 사용량 제한을 추가해야 합니다. 공개 주소가 있다는 것과 다중 사용자 운영 준비가 됐다는 것은 다릅니다.
