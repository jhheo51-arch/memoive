# MEMOIVE 모바일 앱 v03 — Coffee Edition

두 번째 Pinterest 참고 디자인인 `Brew & Browse App UI`의 따뜻한 색감과 정돈된 콘텐츠 탐색 구조에서 영감을 받아 새롭게 만든 버전입니다. 화면을 그대로 복제하지 않고 MEMOIVE의 기록 흐름에 맞게 재구성했습니다.

## 선택 이유

- 커피·도서관 분위기가 콘텐츠를 모으고 다시 읽는 서비스와 자연스럽게 연결됩니다.
- 버건디보다 커피색이 장시간 읽고 개인 생각을 쓰는 화면에서 부담이 적습니다.
- 강한 편집물보다 카드형 서가 구조가 콘텐츠가 늘어났을 때 확장하기 쉽습니다.

## 주요 변경

- 의미가 불분명했던 AI 장식 이미지 제거
- 출처와 글의 맥락이 바로 보이는 아티클 표지로 교체
- 주 3회 목표와 점수 제거
- 기록한 날짜만 표시하는 월별 기록 달력 추가
- 이전 달과 다음 달 이동 가능
- 당근 글의 요약, 핵심 내용, 질문, 나만의 기록 유지
- 링크·이미지·텍스트·음성 입력 시연 흐름 유지

실제 AI 분석, 음성 인식, 이미지 문자 추출, 휴대전화 공유 메뉴는 아직 연결 전입니다.
