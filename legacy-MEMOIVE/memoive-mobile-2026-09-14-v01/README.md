# MEMOIVE 모바일 첫 버전

최종 PRD v0.3의 핵심 경험을 검증하기 위한 모바일 중심 시제품입니다.

## 확인할 수 있는 경험

- 링크, 이미지, 텍스트, 음성 기록 진입
- 입력 유형별 시연용 분석 흐름
- MEMOIVE가 정리한 기록과 나만의 기록 구분
- 나만의 한 줄 추가 및 브라우저 안에 보존
- 기록 검색과 유형 필터
- 주제별 기록 탐색
- 주 3회 질문형 기록 리듬

## 첫 버전의 범위

AI 서버, 실제 음성 인식, 이미지 문자 추출, 모바일 운영체제의 공유 메뉴는 아직 연결하지 않았습니다. 현재 버전은 핵심 화면과 사용 흐름을 검증하기 위한 작동형 시제품이며, 새 기록의 분석 내용은 시연용으로 생성됩니다.

## 확인 방법

로컬 웹 서버에서 `index.html`을 열면 휴대폰 크기에 맞춘 화면으로 동작합니다. 데스크톱에서는 중앙의 모바일 화면으로 표시됩니다.
