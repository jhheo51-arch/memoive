# MEMOIVE 모바일 앱 v02 — Burgundy Edition

실제 당근 팀 블로그 글을 예시로 넣은 두 번째 모바일 시제품입니다. 기존 v01은 그대로 보존되어 있습니다.

## 이번 버전의 방향

- 버건디와 크림을 사용한 편집 노트·스크랩북 분위기
- 실제 글 한 편의 `수집 → AI 정리 → 질문 → 나만의 기록` 흐름
- 링크, 이미지, 텍스트, 음성을 한 입력창에서 받는 상시 기록
- 오늘, 기록 서랍, 주제 책갈피, 나의 리듬 화면
- 브라우저 안에 기록을 저장하는 시제품 동작

## 테스트 예시

- 당근 팀 블로그: 「비개발자로 회의봇 만들기는 처음이라」
- 글의 핵심 내용, 기억할 문장, 제품에 연결하는 질문, 나만의 기록 예시 포함
- 글에 나온 수치는 회사가 공개한 내부 사례 수치라는 점을 상세 화면에 함께 표시

## 현재 범위

화면과 주요 흐름을 확인하기 위한 시제품입니다. 실제 AI 분석, 음성 인식, 이미지 문자 추출, 휴대전화 공유 메뉴 연동은 다음 개발 단계에서 서버와 운영체제 기능을 연결해야 합니다.
