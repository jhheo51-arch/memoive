# MEMOIVE

**저장한 자료에 내 생각을 남기고, 다시 찾아 내 글로 이어 쓰는 웹 서비스입니다.**

[서비스 사용하기](https://memoive.vercel.app/) | [제품 기획서](docs/PRD_MEMOIVE_2026-10-06-v01.md) | [검증 기록](docs/verification.md)

![MEMOIVE 운영 화면](assets/project-overview.png)

## 무엇을 할 수 있나요?

`자료 기록 → 내 생각 남기기 → 다시 찾기 → 글로 이어 쓰기`

- 공개 글, 영상 자막과 직접 입력한 내용을 기록합니다. 자동 읽기가 어려우면 본문을 직접 넣을 수 있습니다.
- 원문, AI 해석과 내 생각을 구분해 보관하고 단어로 검색합니다.
- 기록에서 편집 가능한 초안을 만들고 출처와 함께 저장합니다. AI 표현 제안은 선택해서 사용합니다.

저장 개수보다 **내 생각이 남고 실제 글로 이어지는가**를 중요하게 봤습니다. 제작자가 문제와 기록 흐름, 개선 우선순위를 정하고 Codex가 코드 작성과 검사를 보조했습니다.

## 어디까지 확인했나요?

저장 실패, 검색, 백업 복원, 동시 수정과 출처 보존을 합성 자료로 검사합니다. 두 개의 필수 브라우저 검사도 자동 실행하며, 오래된 저장 요청은 최신 기록을 덮어쓰지 못하도록 막습니다.

외부 사용자의 글쓰기 시간 단축이나 만족도는 아직 측정하지 않았습니다. 모든 사이트의 본문 추출과 AI 해석의 정확성을 보장하지 않습니다. 온라인 동기화는 한 사람의 기기 연결 방식입니다.

## 직접 실행하기

Python이 설치된 환경에서 저장소 폴더의 터미널에 입력합니다.

```sh
python -m http.server 4182 --directory .
```

브라우저에서 http://127.0.0.1:4182/ 를 엽니다. 화면은 인증값 없이 열리지만, 운영 AI 서버의 허용 주소 설정에 따라 로컬 AI 요청은 거절될 수 있습니다.

<details>
<summary>자동 검사 실행 — Node.js 24 이상</summary>

```sh
npm ci
npx playwright install chromium
npm test
```

합성 자료 검사와 브라우저 검사 두 개를 모두 실행합니다. 브라우저 검사는 임시 로컬 서버를 사용하고 외부 요청을 차단합니다. 개별 명령과 저장 정책은 [실행 및 검증 상세](docs/README-DETAILS.md)에 있습니다.
