# MEMOIVE

자료를 저장한 순간의 생각을 남기고, 필요한 때 다시 찾아 글과 기획으로 이어 쓰는 웹 서비스입니다.

[서비스 사용하기](https://memoive.vercel.app/) | [제품 기획서](docs/PRD_MEMOIVE_2026-10-06-v01.md) | [검증 기록](docs/verification.md) | [문서 안내](docs/README-DETAILS.md)

## 소개

참고할 글과 영상을 모아 두어도 시간이 지나면 왜 저장했는지 잊고, 실제 글을 쓸 때는 자료를 다시 찾게 됩니다. MEMOIVE는 제품 사례와 참고 자료를 모아 기획안, 포트폴리오와 글을 쓰는 사람을 대상으로 이 흐름을 연결합니다.

중요하게 본 것은 저장 개수보다 **자료에 남긴 내 생각이 실제 결과물에 쓰이는가**입니다. 원문, AI 해석과 사용자 의견을 따로 보관하고, 사용자가 직접 고친 글을 중심으로 작업을 이어가도록 설계했습니다.

## 사용 흐름

**자료 기록 → 내 생각 남기기 → 다시 찾기 → 글로 이어 쓰기**

1. 공개 글 주소, 영상 주소 또는 직접 작성한 텍스트를 기록합니다.
2. 원문과 요약, 근거를 확인하고 `내 생각`을 남깁니다.
3. 제목이나 생각에 쓴 단어로 기록을 다시 찾습니다.
4. 기록에서 초안을 만들고 편집합니다. AI 표현 제안은 필요할 때 선택합니다.
5. 글을 저장한 뒤 다시 열어 본문과 참고 기록을 확인합니다.

## 주요 기능과 판단

| 기능 | 선택한 방식과 이유 |
|---|---|
| 자료 입력 | 공개 글과 영상 자막을 먼저 읽고, 실패하면 직접 입력할 수 있게 해 기록 흐름을 이어갑니다. |
| 생각 보관 | 원문 인용, AI 해석과 내 의견을 구분해 어디에서 나온 내용인지 확인합니다. |
| 다시 찾기 | 제목, 본문과 생각의 단어로 검색합니다. 의미 검색이나 개인화 추천 모델은 아닙니다. |
| 글쓰기 | 기기에서 편집 가능한 초안을 만들고 출처를 연결합니다. AI 응답이 직접 고친 글을 자동으로 덮어쓰지 않습니다. |
| 기록 보호 | 기기 저장, JSON 백업과 소유자 연결 방식의 온라인 동기화를 제공합니다. 오래된 수정 요청은 최신 기록을 덮어쓰지 못하게 합니다. |

온라인 동기화는 한 사람의 여러 브라우저를 연결하는 방식입니다. 새 브라우저에서는 연결 절차가 필요하며, 여러 사람이 함께 편집하는 서비스는 아닙니다.

## 확인한 결과와 남은 검증

저장 실패, 용량 초과, 백업 복원, 동시 수정, 검색, 출처 보존과 입력 초기화를 합성 자료로 검사합니다. `npm test`에는 두 개의 필수 브라우저 검사도 포함됩니다. 자동 본문 읽기가 막히는 경우의 직접 입력과 긴 본문 처리 등은 [검증 상세](docs/README-DETAILS.md)에 기록했습니다.

아직 외부 사용자의 글쓰기 시간 단축과 만족도는 측정하지 않았습니다. 모든 사이트의 본문 수집, 자막의 정확성, AI 해석의 타당성을 보장하지 않습니다. 다음 검증은 처음 쓰는 사람이 핵심 흐름을 완료하는지, 며칠 뒤 기록을 실제 글에 재사용하는지 확인하는 것입니다.

## 직접 실행하기

Python이 설치된 환경에서 저장소 최상위 폴더의 터미널에 입력합니다.

```sh
python -m http.server 4182 --directory .
```

브라우저에서 http://127.0.0.1:4182/ 를 엽니다. 정적 화면은 인증값 없이 열리지만, 운영 AI 서버의 허용 주소 설정에 따라 로컬 AI 요청은 거절될 수 있습니다.

자동 검사는 Node.js 24 이상에서 실행합니다.

```sh
npm ci
npx playwright install chromium
npm test
```

브라우저 검사는 임시 로컬 서버와 새 저장 공간을 사용하며 외부 요청을 차단합니다. 검사 명령과 저장 정책은 [실행 및 검증 상세](docs/README-DETAILS.md)를 참고하세요.
