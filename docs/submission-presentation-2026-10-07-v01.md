# MEMOIVE 제출 및 발표 요약

## 어떤 문제로 시작했는가

좋은 기사나 영상을 저장해도 나중에 다시 쓸 때는 자료를 다시 찾고, 왜 저장했는지 떠올리고, AI에게 맥락을 다시 설명해야 했습니다. MEMOIVE는 자료가 없는 문제보다 저장한 자료와 당시의 생각이 결과물로 이어지지 않는 문제에 집중했습니다.

## 구현한 핵심

- 링크, 글, 이미지, 음성, 영상을 기록합니다.
- AI가 `자료 정보 → 핵심 요약 → 주요 근거 → 해석과 한계 → 나에게 남길 질문 → 다시 쓸 방법` 순서로 정리합니다.
- 자료 작성자의 주장, AI 해석, 사용자 생각을 구분합니다.
- 저장한 생각과 선택한 기록을 창작 화면으로 이어 제목과 본문을 직접 편집합니다.
- 기록과 결과물은 TOBEA Supabase 데이터베이스에, 이미지와 음성 원본은 비공개 Supabase Storage에 보관합니다.
- Vercel, Cloudflare Pages, GitHub Pages 같은 허용된 화면 주소가 같은 Vercel 기록 API를 사용하도록 구성했습니다. 새 주소나 새 브라우저에서는 개인 연결 링크를 한 번 열어야 합니다.

## 느낀 점과 배운 점

AI 답변의 품질만 높여도 반복 사용이 생기지는 않았습니다. 사용자가 남긴 자료와 생각을 안전하게 보관하고 다음 작업에서 다시 꺼내는 경험이 필요했습니다. 새 기능보다 저장 실패, 충돌, 복구 같은 신뢰 문제를 먼저 다뤄야 했고, 저장 데이터 수와 사용자 효과를 같은 성과로 말하지 않는 것이 중요했습니다.

## 현재 확인한 범위와 한계

2026-10-07 기준으로 Supabase에 기록 13개와 결과물 2개가 저장되어 있고, 운영 화면에서 기준 데이터를 불러온 것을 확인했습니다. 이 수치는 사용자 수나 서비스 효과가 아닙니다. 외부 사용자의 수요, 실제 시간 단축, 장기 반복 사용은 아직 확인하지 못했습니다.
